# WarmHome UA — лендинг

Сайт: https://warmhome.in.ua (GitHub Pages)

- `index.html` — сторінка
- `assets/tw.css` — зібраний Tailwind CSS (генерується, руками не редагувати)
- `assets/icons.js` — лише ті іконки Lucide, що використовуються на сторінці

## Перезбірка стилів після зміни класів у HTML

```
npx tailwindcss@3 -c tailwind.config.js -i assets/tw.src.css -o assets/tw.css --minify
```

Після перезбірки оновіть `?v=...` у посиланнях на `assets/tw.css` та `assets/icons.js` в `index.html`, щоб браузери не брали стару версію з кешу.

## Структура сайту

- `/` — головна: каталог усіх товарів (`index.html`)
- `/products/<slug>/` — сторінка товару (форма «Купити в 1 клік», Нова Пошта, відгуки, «Дивіться також»)
- `/catalog/` — стара адреса, перенаправляє на головну
- `assets/products.js` — список усіх товарів: з нього будуються каталог, «Дивіться також» і кошик
- `assets/cart.js` — кошик (бічна панель, оформлення, відправка в Google-таблицю + Telegram)
- `assets/shop.js` — картки товарів, `assets/site.css` — спільні стилі й темна тема

## Як додати новий товар

1. Скопіювати `products/obigrivach-ptc-ph16/` у `products/<новий-slug>/` і замінити тексти, фото, ціну, `PRODUCT`, `data-current` та `data-add-to-cart`.
2. Додати блок товару в `assets/products.js`.
3. Перезібрати стилі й оновити `?v=` у посиланнях на файли.
4. Головне фото: `assets/img/<назва>-main.webp` (1024 px) і `<назва>-main-600.webp`. Для світлої теми поруч кладуться версії на світлому тлі: `<назва>-main-light.webp` і `<назва>-main-600-light.webp` — сайт підставляє їх сам, коли відвідувач вмикає світлу тему.
5. Після заміни будь-якого фото оновіть `?v=` у посиланнях на фото (скрипт imgver.py), інакше браузери показуватимуть старе фото з кешу.
